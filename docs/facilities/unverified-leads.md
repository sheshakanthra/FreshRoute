# Unverified facility leads — for manual follow-up

**Compiled 2026-09-10.** Nothing on this page is in the database, and nothing on this page
should be inserted without a human confirming it first. See
[sourcing-report.md](sourcing-report.md) for how each source was assessed.

Two different kinds of "unverified" are listed separately, because they need different
follow-up:

- **§1** — names that came from a **real primary government PDF** whose table could not be
  parsed without misattributing capacities. The *names* are trustworthy; the *numbers* are
  not carried over. Follow-up = read the PDF by eye.
- **§2** — facility records that exist in a source we could not open. Follow-up = get access.

---

## 1. NHB Tamil Nadu cold-storage subsidy list — names readable, figures NOT transcribed

**Source:** `https://www.nhb.gov.in/doc/Tamilnadu.pdf` (accessible 2026-09-10)
**What it is:** NHB cold-storage subsidy sanctions, **1999-2000 → 2012-13**. Each entry has
year of sanction, unit name + address, category, capacity in MT, project cost and subsidy.

**Why it is here and not in the DB:** the PDF's name/address cells wrap across multiple
lines while the numeric columns drift, so automated extraction paired capacities with the
wrong facilities. Details in sourcing-report.md §2.2. **The capacities printed in this PDF
are deliberately not reproduced below** — reading a number off a mis-parsed row is exactly
the error being avoided. Capacity must be read off the PDF by eye, per row.

**Vintage warning:** the newest entry is **2012-13 — roughly 13 years old**. A subsidy
sanction is evidence a facility was *funded*, not that it is *operating today*. Every name
below needs an operating-status check before it means anything.

## 2. NCCD registered facilities — records exist, access required

**Source:** `https://nccd.gov.in/graphql` (endpoint live 2026-09-10; introspection open,
data authenticated).

We can prove these records **exist and are structured**, but cannot see any of them. The
public search endpoint returns a `MaskedAddress` and its result type has **no `name` field
at all** — facility identity is withheld by design until login.

Not a single facility name is recoverable, so nothing is listed here. What is recoverable is
**what the fields will be once someone logs in** — and it is the exact set this project is
missing:

| NCCD field | Fills our column |
|---|---|
| `pricePerTonnePerDay` | `storage_facility.cost_per_kg_per_day` |
| `minTemperature` / `maxTemperature` | `storage_facility.storage_temp_c` |
| `minHumidity` / `maxHumidity` | `storage_facility.storage_humidity_pct` |
| `capacity` | `storage_facility.capacity_kg` |
| `commodities` | whether it takes **tomato** specifically |
| `address` (unmasked, with `location` geometry) | `lat` / `lon` / `district` |
| `status`, `establishedOn` | operating status — the gap §1 cannot close |

**Action: register an account on nccd.gov.in.** This is the highest-value single follow-up
identified in this whole exercise.

## 3. Claims seen but NOT confirmed against any facility-level directory

Recorded so they are not re-researched from scratch, and so no one mistakes them for row
counts we can back:

- **"111 cold storage units / 13,565 MT"** — stated by the TN Dept of Agricultural
  Marketing. The unit list itself *was* verified and inserted (all 111, and the parsed
  capacities sum to exactly 13,565 MT). **Operating status is not confirmed for any of
  them** — the page asserts they "are in use" but carries no last-updated date and the
  construction years end in 2016.
- **"3,908 MT in Primary Processing Centres"** — aggregate only. **No facility list
  published.** Would be a real processing-facility source if a list exists — worth asking
  the department for.
- **"54 MT of cold storage in Uzhavar Sandhais"** — aggregate only, no list. Directly
  relevant, since our two anchor markets (Kumbakonam, Krishnagiri) are both Uzhavar
  Sandhais. **Which** sandhais have these cold rooms is not published anywhere found.
  Worth a specific question to the department.
- **"Cold storage in 6 districts and Solar Micro Cold Storage in 20 districts under NABARD
  assistance, Rs 100 crore"** — stated on the same page as **future/planned** work. No
  districts named, no facilities exist yet. **Do not treat as inventory.**
- **"Tamil Nadu has 59 sanctioned cold chain projects under PMKSY"** — appeared in a
  secondary search summary and **contradicts the primary MoFPI document**, which lists
  **26** for Tamil Nadu as on 30.06.2026. The primary document was used; the "59" figure is
  unverified and probably conflates schemes or years. Flagged so it is not adopted later.
- **ABC Fruits (Krishnagiri) as a tomato processor** — MoFPI confirms the company, the
  district, sector `F&V`, and *Completed* status, so it is in `processing_facility`.
  That it processes **tomato specifically** was **not stated by any primary source** and was
  not inferred. Confirm by phone before relying on it for PROCESS.
